# @gtivr4/a1-design-system-react Changelog

## 0.18.0 — 2026-06-19

### Added

- **ToolbarGroup `labelMode`** (`"all"` | `"selected"`, default `"all"`) — `"selected"` shows the label only on the currently-selected option and renders the rest **icon/swatch-only** (a `"none"`/empty value falls back to the standard none icon); non-selected options keep an `aria-label` so the accessible name stays stable. For swatch/variant pickers where only the chosen option needs naming — e.g. a Section surface/gradient picker or a Button/IconButton variant picker. Added a `Label on selected only (swatch picker)` story.
- **Grid `gap="none"`** — a zero gap (matches the shared `resolveSpacing` "none" → 0 convention). Added to the `GapKey` type and the Gap Scale / argType stories.
- **Grid responsive 8-column classes** — `columns={{ … }}` now supports `8` at every breakpoint (`.a1-grid--{xs…xl}-8`), alongside the existing 1/2/3/4/6/12. Fixed (non-responsive) `columns={8}` already worked via the inline column variable. Added `8` to the Column Counts story.
- **Autocomplete grouped + icon options** — options gained **`icon`** (a Material Symbols glyph rendered beside the option, chip, and selected value) and **`group`** (a sticky category heading before each group; results are ordered by each group's first appearance). Also **`maxVisible`** (+ `moreText(shown)`) caps how many options render for very large lists (e.g. an icon picker), hiding the rest behind a "keep typing" footer. Fully backward compatible. Added `Grouped options + icons` and `Grouped + capped (maxVisible)` stories.

### Changed

- **Accordion divider spacing** — when `divider` is set, the open panel now has a `padding-block-start` (scaled to the accordion `size`) so the first content item no longer sits directly against the divider line.
- **SegmentedControl sizing** — the segment icon is one step larger (`1.25em`) so glyphs read clearly; the default (md) segment inline padding steps down one notch (`component.segmented.segmentPaddingInline` 0.75rem → 0.5rem; affects md only, since sm/lg carry their own padding tokens); and the sm size tightens the icon↔label gap.

### Fixed

- **SegmentedControl `fullWidth`** now actually fills its container. `.a1-segmented--full-width` set `display: flex` but no width, so inside a centering flex/grid parent it stayed content-width; it now also sets `inline-size: 100%` so the equal-width segments stretch as intended.

## 0.17.0 — 2026-06-18

### Added

- **Figure `placeholder`** (boolean, default true) + **`placeholderIcon`** (default `"image"`) — when `src` is missing or fails to load, Figure now renders a tokenized diagonal-stripe placeholder pattern with a centered icon instead of a broken image. Respects `aspectRatio`/`size` (4:3 fallback box). Added a `Placeholder pattern` story. Set `placeholder={false}` to opt out.
- **DataTable column `type="image"`** — renders a small fixed-size thumbnail (`object-fit: cover`, ~2.5rem; ~2rem at compact density). The cell value is an image URL string or `{ src, alt }`; an empty value renders a dashed placeholder.
- **Autocomplete** — a new filtering combobox component, single- or multi-select (`multiple`). Filters `options` as you type; multi mode renders removable chips. Optional `allowCreate` (+ `onCreate`) offers an "Add …" entry so users can add a value that isn't in the list. Matches the field family (`size`, `label`, `hint`, `error`, `required`, `disabled`) and follows the ARIA combobox/listbox pattern with full keyboard navigation (Arrow Up/Down, Enter, Escape, Backspace to remove the last chip). Exported from the package; `Single`, `Multiple`, `Multi-select + create`, and `Sizes` stories.
- **SegmentedControl `labelMode`** (`"all"` | `"selected"`, default `"all"`) — `"selected"` shows the label only on the currently-selected segment and renders the rest **icon-only**, using each option's `ariaLabel`/`label` for its accessible name (options without an icon keep their label so they never render blank). Formalizes the compact "active = icon + label, others = icon" pattern. Added a `Label on selected only` story.

### Fixed

- **SegmentedControl `size`** now actually changes the control. The `sm`/`lg` classes previously had no CSS, so the `size` prop had no visible effect. `sm` now uses tighter padding and a font size one step down (`body-xs`); `lg` uses roomier padding and `body-md`. Added `component.segmented.segmentPaddingBlockLg` / `segmentPaddingInlineLg` tokens.

## 0.16.0 — 2026-06-18

### Added

- **Banner `variant="calendar"`** — an event/date callout. A tokenized date block (a new `date` prop — accepts a `Date`, an ISO date string, or `{ month, day }`) replaces the status icon; a new `eyebrow` overline sits above a larger `title`; and `action`/`onDismiss` continue to work. The `neutral` status defaults the date block to the action colour, but any `status` still tints it. Month names render in sentence case (never uppercased). The root uses `role="group"` (not `role="alert"`) since a date callout is not an alert. Added `Calendar`, `CalendarWithLink`, and `CalendarStatuses` stories and a1-web configurator support (Variant gains Calendar; eyebrow + Date month/day fields; icon controls hidden for the calendar variant). React only.

## 0.15.0 — 2026-06-17

### Added

- **SplitButton** — a new component: a primary action joined to a caret toggle that opens a `Menu` of related/secondary actions. Composes the A1 `Button` + `Menu`, so variant/size/icon/loading/disabled, keyboard, and focus come from those. Props: `children` (main label), `onClick`, `variant`, `size`, `icon`, `iconPosition`, `loading`, `disabled`, `actions` (`{ id, label, icon?, disabled?, onClick? }[]`), `menuLabel`, `toggleLabel`. The toggle carries `aria-haspopup="menu"` / `aria-expanded`. CSS-variable architecture over existing button/divider tokens (the two targets share one pill outline with a hairline divider). Exported from the package; Storybook stories (Default, Variants, Sizes, WithIcon, Disabled); surfaced in the a1-web Button configurator via a **Split (menu)** toggle. React only.
- **Accordion `subtext` + `divider`** — `subtext` shows secondary info in the trigger after the label, visible only while collapsed (a glanceable summary, e.g. applied settings) and hidden when open; it truncates with an ellipsis. `divider` adds a bottom border to separate stacked accordions. The trigger also lost its border-radius and uses a more compact inline padding. Added a `Subtext` story.
- **IconButton `sm` size** — a 24×24px target (the WCAG 2.2 AA minimum target size) with a 16px icon, for dense toolbars. React + Pure classes, types, stories, and the a1-web configurator.
- **Slider `bubbleLabel`** — an alternate label for the value bubble (visual only; `aria-valuetext` is unchanged). A node is used as-is; a function receives the current value and the active detent. When omitted, the bubble keeps its current content. Useful for spelling a size out in the bubble (e.g. "Small") while the detent under the track stays "SM" — the a1-web size/spacing sliders use this. Added `Bubble label (long size names)` and `Bubble stays within the track at the ends` stories.
- **Slider `variant="subtle"`** — shows the selection (fill, thumb, active detent) in neutrals instead of the action colour. Added a `Subtle variant` story and a configurator control; used for the Section Content width slider.
- **Slider `size` + visible `label`** — `size` (`"compact" | "default" | "comfortable"`) mirrors the field family so a Slider sits naturally beside form fields, scaling the label, detent labels, track, and thumb. `label` now renders a **visible field label** above the control (associated via `htmlFor`, still the accessible name); use `aria-label`/`aria-labelledby` for an invisible name. Track heights increased (compact / default / comfortable = `--base-spacing-6` / `8` / `12`). Added a `Sizes` story and configurator controls.
- **Section `borderSides`** — control which sides the border is drawn on. `"all"` (default) keeps all four; pass an array like `["top", "bottom"]` for a partial border (an empty array draws none). Requires `borderSize`; implemented with per-side `border-width` CSS variables. Added a `Border sides` story and a1-web configurator controls (an "All" button + per-side toggles).
- **Toolbar `swatch`** — `ToolbarToggle` / `ToolbarButton` and `ToolbarGroup` options accept a `swatch` (any CSS color) that renders a small bordered colour chip inside the tool (the border stops a light swatch from bleeding into the bar). Used in the a1-web Section Surface control to preview the surface colours.
- **`semantic.font.size.body.3xs`** (0.5rem) — a new smallest body type step (`base.font.size.scale.25`).
- **Toolbar** — new compact container for grouped editing controls (think a text-editor toolbar, or the component configurator), denser than a ChoiceGroup (which is retained for full-size selectors). Compositional: `Toolbar` (`role="toolbar"`) + `ToolbarToggle` (on/off, e.g. bold), `ToolbarButton` (action), `ToolbarGroup` (single-select button group with radio semantics + roving-tabindex arrow nav; set `columns` for a grid like a 3×3 crop picker; icon-only or `showLabels`), `ToolbarMenu` (a button that opens a dropdown `Menu` of choices — e.g. a text-size t-shirt-size picker, or a list-type none/bulleted/numbered/checklist picker; caret + `aria-haspopup`/`aria-expanded`, active item marked), and `ToolbarDivider` between tools. Subtle surface, clearly highlighted selection, and an exported standard `TOOLBAR_NONE_ICON` (`block`) auto-applied to "none" options. Optional `label` renders a compact caption above the bar (matches the ChoiceGroup compact label); optional `overlay` lifts the bar onto a floating, elevated surface for a toolbar that hovers over page content (the consumer positions it); optional `fullWidth` stretches the bar to fill its container with the tools growing to share the width (default is `fit-content`). The bar gains a border in the accessible theme and under OS high-contrast (`prefers-contrast: more` / `forced-colors`). One size for now; React only.
- **Toolbar overflow** — the bar now wraps its tools onto new rows instead of overflowing its container (caps to `max-inline-size: 100%`; non-grid groups wrap their own buttons). No horizontal scrolling.
- **Toolbar responsive labels** — `showLabel` (`ToolbarToggle` / `ToolbarButton` / `ToolbarMenu`) and `showLabels` (`ToolbarGroup`) now accept a responsive `{ xs?, sm?, md?, lg?, xl? }` object as well as a boolean, so a tool can show its label at wide breakpoints and collapse to icon-only when space is tight (cascades xs → xl). When a label can be hidden at any breakpoint the tool keeps an `aria-label`, so its accessible name stays stable. New `ToolbarShowLabel` type; `Responsive labels` Storybook story.
- **Menu** — the selected/active `MenuItem` now uses the same highlight as a selected TreeMenu item: a solid action-background fill with action-foreground text/icon (and hover/pressed/focus action states), replacing the previous left-border + tinted-surface treatment.
- **Slider** — new range-input component with optional **detents** (snap stops with optional labels — or an **icon** instead of the label, e.g. alignment icons — e.g. None / XS / SM / MD / LG), continuous (`min`/`max`/`step`) or detent mode, and a value bubble that follows the thumb and flips above/below to stay in the viewport (`showValue`, `valuePosition`, `formatValue`). Built on a native `<input type="range">`, so keyboard (arrows, Home/End, Page Up/Down), focus, touch, and form semantics work out of the box; the current value is announced via `aria-valuetext`. CSS-variable architecture (`--a1-slider-*`) over existing tokens. Storybook stories + a1-web configurator. One size for now; React only.
- **Figure `cropRect`** — a freeform, non-destructive crop. Pass `cropRect={{ x, y, width, height }}` (fractions 0–1 of the natural image) to show just that sub-rectangle; it's rendered with a CSS clipping wrapper (the image is never modified) and takes precedence over `aspectRatio`/`crop`. The a1-web configurator gained an interactive in-preview crop editor (draw a freeform rectangle, dim outside, drag edges/corners, constrain to a standard ratio via a floating overlay Toolbar) that produces this metadata. Added a `FreeformCrop` story. (React only so far — not yet replicated in Pure.)
- **Figure aspect ratios** — added more standard fixed ratios: `4:3`, `3:2`, `2:3`, `3:4`, `9:16`, `21:9` (alongside `16:9` and `1:1`). React + Pure classes, types, Storybook control, and the a1-web configurator.
- **Figure size scale + align + radius** — the Figure width scale is now `3xs` / `2xs` / `xs` / `sm` / `md` / `lg` / `xl` / `xxl` (5 / 8 / 12 / 20 / 30 / 40 / 50 / 60rem), including center-align overrides. `align` gained `"none"` (now the default — the figure flows normally; `start` / `center` / `end` are explicit alignments). Radius is square by default — the old base used an undefined token that resolved to 0, identical to `radius="none"`, so the duplicate "Default" option was removed from the a1-web Radius control. The a1-web configurator also hides the Crop control unless an `aspectRatio` is set (crop has no effect on a natural-ratio image). Reflected in `Figure.d.ts`, the "Size scale" story, the a1-web configurator, and the editor Figure config bridge.
- **Figure `aspectRatio` + `crop`** — Figure can now lock the image to a fixed aspect ratio (`"16:9"` or `"1:1"`), filling and cropping via `object-fit: cover`. The `crop` prop sets the focal point — `center` (default), `top`, `bottom`, `left`, `right`, `top-left`, `top-right`, `bottom-left`, `bottom-right` — mapped to `object-position`. CSS variable architecture: ratio modifiers set `aspect-ratio`, crop modifiers set `--a1-figure-crop`. Replicated in the Pure package (`.a1-figure-ratio-16-9` / `-1-1`, `.a1-figure-crop-*`), the a1-web configurator, and Storybook ("Aspect ratios" + "Crop points" stories).
- **IconButton `as` / `href`** — IconButton now accepts `as` (default `"button"`). Pass `as="a"` with an `href` to render it as a navigation link while keeping the icon-button styling. When rendered as an anchor, `disabled` maps to `aria-disabled` (the native `disabled` attribute does not apply to anchors). Added a Storybook "As link" story and the `as`/`href` types.

### Changed

- **Button label wrapping** — a long button label now wraps onto multiple lines (centered) and the button grows taller, instead of being clipped to a fixed-height pill. The button keeps its standard target height for a single line via `min-height` (the fixed `height`/`max-height` and `white-space: nowrap` were removed; `overflow-wrap: anywhere` breaks an over-long word).
- **Section block flow when unaligned** — a Section with no `align` now flows as **block** (block children fill the width; natural-width content like a Button or Badge keeps its size) instead of a stretch grid. When a `gap` is set without alignment, the spacing is recreated with margins between direct children; an aligned Section (or `height="hero"`) still uses grid with `justify-items` and grid-gap.
- **Slider value bubble stays within the track** — the floating value bubble is now anchored by progress (left-aligned at the start, centered mid-track, right-aligned at the end) and its caret tracks the thumb, so the bubble no longer spills past the control's edges at the extremes.
- **Card padding 20 → 16px** — `base.space.card.padding` now resolves to `{base.spacing.16}` (1rem) instead of `{base.spacing.20}` (1.25rem), so `--component-card-padding` is 16px for consistency with the core spacing step. Rebuilt token + html-css outputs.
- **Toolbar surface** — the bar's default background is now `--semantic-color-surface-raised` (was `surface-panel`), so it reads clearly on panel-coloured surfaces like the configurator/editor side panels.
- **Toolbar selected state** — a selected radio-group item (`aria-checked`) no longer shows a hover/active change, since it can't be deselected (clicking it does nothing). Toggles (`aria-pressed`), which can be turned off, keep their hover feedback.
- **IconButton `lg` icon** — the large icon button's icon is now 32px (was an undersized 20px), so it reads correctly at the 3.5rem target.
- **Toolbar `label` size** — the optional caption above a Toolbar is now two type steps smaller (`--semantic-font-size-body-3xs`, a new 0.5rem token below the compact form-label size).

### Fixed

- **Toolbar stretched to full width in flex columns** — a labelled `<Toolbar label>` placed in a column flex container (e.g. a `Stack` with the default `align-items: stretch`, as in the component configurators) was forced to full width instead of `fit-content`. The `.a1-toolbar-field` wrapper now uses `align-items: flex-start`, so the bar keeps its natural width (a `fullWidth` bar still fills, since it sets its own `inline-size: 100%`).
- **Menu positioning inside transformed ancestors** — a `Menu` whose anchor sits inside an element with a CSS `transform`/`filter` (which becomes the containing block for the menu's `position: fixed`) was misaligned — e.g. a `ToolbarMenu` opened inside an `overlay` `Toolbar`. The menu now measures where it actually landed and corrects by the containing-block offset so it stays anchored to the viewport.
- **Prop forwarding** — `Banner`, `MessageBadge`, `MessageEmptyState`, `Pagination`, `TopHeader`, `BottomDrawer`, and `Accordion` now spread `...rest` (and merge `className`) onto their root element. They previously dropped unknown props, which broke consumers that rely on passing through DOM attributes / event handlers (e.g. the a1-web Editor's click-to-select).

See `ai/components.md` (Maintenance log) for the full per-component history.
