    A1:Figma help

    Quick orientation for the current plugin modes.

    • Audit checks a selection, shows an interactive report in the plugin, and can print the design-system report card to the canvas.
    • Build & Fix combines conversion and quick-add in one categorized component list. Fix converts the selection; Build adds a fresh component. Grid columns can round-trip from layer names like Grid - {xs:1, md:2, lg:4}.
    • Publish combines Preview & Sync, responsive breakpoint previews, and A1 page sync. Playground mode is non-destructive and syncs exported JSON to the local playground; Live Sync connects Figma roots to local A1 project pages, renders linked pages into Figma, creates new A1 pages, and syncs Figma changes back to A1.
    • Patterns imports reusable A1 patterns as local Figma component sets with one variant per breakpoint, and can push a selected local Pattern set or variant back to A1.
    • Export library manifest is a maintainer tool for refreshing the checked-in A1 library manifest after publishing component, text style, or variable changes. Consumer files should import from the built-in manifest automatically.

    Tabs panel content

    Tabs need an explicit content marker so the plugin knows which Figma layer belongs to which A1 tab panel. Name a nearby frame, Section, Stack, or Grid with {tab=Dashboard}, where Dashboard matches the visible tab label. On export, that layer's supported A1 content is sent as the Dashboard panel content. Repeat the pattern for each tab that needs its own panel.

    Example: place a Tabs component with a Dashboard tab, then add a nearby Section named Dashboard content {tab=Dashboard}. Audit will alert you when a Tabs component has no connected panel content.
