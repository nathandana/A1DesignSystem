A1 Design System — MCP server

A remote Model Context Protocol server exposing the A1 Design System's component registry, design tokens, design rules, and page-definition contract to AI coding agents.

Endpoint: POST /mcp (MCP Streamable HTTP, stateless — one JSON-RPC request per response).

Connect a local MCP client, e.g. with the Claude Code CLI:

claude mcp add --transport http a1-design https://mcp.a1design.app/mcp

Tools: list_components, get_component, search_tokens, get_token, list_themes, list_rules, list_page_types.

Resources: a1://docs/agent-brief, a1://docs/page-definition-standard.
