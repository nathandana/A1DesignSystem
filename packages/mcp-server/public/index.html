A1 Design System — MCP server

Help your agent build with the A1 Design System. This Model Context Protocol (MCP) server provides component APIs, patterns, tokens, rules and JSON contracts. The recommended workflow is to follow A1’s rules, generate project JSON, validate it and share a rendered A1 preview.

Connect your agent

Use this URL in your MCP client’s server configuration:

https://mcp.a1design.app/mcp

For Claude Code:

claude mcp add --transport http a1-design https://mcp.a1design.app/mcp

The endpoint accepts MCP Streamable HTTP requests and does not require an account.

From JSON to an A1 preview

  1. Read the model and rules. Call get_json_model for the schema, starter and mandatory A1 rules, including visible content exceptions. It defaults to a project bundle. Use linked pages for a website; use a single page when that is what the user requests.
  2. Build with A1. Consult get_component and get_pattern before authoring. Use supported props, patterns, tokens and project navigation instead of guessing their shapes.
  3. Validate and repair. Send the complete project to validate_json. Fix errors at the returned JSON paths, review warnings and coverage, then validate again.
  4. Create and review a preview. Send the validated JSON to create_preview. Open its A1 preview URL, check responsive layout and accessibility, and submit revised JSON for a new preview when needed. Return the preview URL as the primary handoff.

Preview links last 30 days and work for anyone with the link. Choose Edit as project in the preview to edit a copy: guests use browser-local storage, while signed-in users use their workspace. Creating a preview does not publish or import a workspace project.

What validation checks

The shared validator checks JSON structure, component props, project references, formal pattern contracts and automated content rules. All-caps content and casing transforms produce errors that block new previews and imports. Sentence-case heading warnings remain advisory to allow review of proper names.

Diagnostics identify the rule, exact JSON path and offending text, with a suggested correction or recovery instruction. Narrow acronym, size and name exceptions are documented in the rules; invalid drafts remain editable for repair.

A valid result is not a full compliance check. Coverage reports what was checked and what still needs rendering or human review, including dynamic content, responsive layout, contrast, keyboard behavior and screen-reader experience.

Use the React library

For React library code or npm integration, call get_react_setup. It provides the install command, peer requirements and setup guidance for CSS, fonts, responsive breakpoints, themes and providers. For site requests, start with the JSON and preview workflow above.
