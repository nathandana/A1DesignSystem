Typography

A1 Pure maps the full A1 type scale to native HTML heading and text elements. Every heading level, paragraph size, and inline element is styled directly — no class attributes required.

Headings

All six semantic heading levels are styled with the A1 heading scale, progressing from display size at <h1> down to a compact label size at <h6>.

<h1>Heading 1</h1>
<h2>Heading 2</h2>
<h3>Heading 3</h3>
<h4>Heading 4</h4>
<h5>Heading 5</h5>
<h6>Heading 6</h6>

Paragraphs

The body type scale runs from xs up through xl. The default <p> renders at the md size.

<p>A standard paragraph of body text.</p>

Muted text

Wrap content in <small> to render it at a reduced size in the muted foreground color — suitable for captions, metadata, and supporting detail.

<p><small>Supporting detail or caption text.</small></p>

Inline elements

All standard HTML inline elements are styled from A1 tokens with no class attributes.

<strong>Bold</strong>
<em>Italic</em>
<a href="#">Link</a>
<code>inline code</code>
<kbd>⌘K</kbd>
<mark>Highlighted</mark>
<abbr title="HyperText Markup Language">HTML</abbr>

Blockquote — border

A plain <blockquote> receives a left-border treatment using the A1 border and spacing tokens.

Good design is as little design as possible. Less, but better — because it concentrates on the essential aspects, and the products are not burdened with non-essentials.

Dieter Rams — Ten Principles for Good Design 
<blockquote>
  <p>Quote text here.</p>
  <cite>Author — Source</cite>
</blockquote>

Blockquote — feature

Wrapping a <blockquote> in a <figure> applies the feature variant — a centered, visually prominent treatment for pull quotes.

<figure>
  <blockquote>
    <p>Quote text here.</p>
    <cite>Author</cite>
  </blockquote>
</figure>

Blockquote — accent

Wrapping a <blockquote> in an <aside> applies an accent background — useful for callouts and highlighted asides within body copy.

Design is not just what it looks like and feels like. Design is how it works.

Steve Jobs 
<aside>
  <blockquote>
    <p>Quote text here.</p>
    <cite>Author</cite>
  </blockquote>
</aside>

Code blocks

Inline <code> renders in the system monospace font with a subtle background. Block-level <pre><code> adds a panel surface, border, and horizontal scrolling on narrow viewports.

<p>Inline <code>code</code> in a sentence.</p>

<pre><code>/* block code */
button { background: var(--token); }</code></pre>

Lists

Both ordered and unordered lists receive proper indentation, spacing, and nested list support.

<ul>
  <li>Item one</li>
  <li>Item two
    <ul>
      <li>Nested item</li>
    </ul>
  </li>
</ul>

<ol>
  <li>First step</li>
  <li>Second step</li>
</ol>
