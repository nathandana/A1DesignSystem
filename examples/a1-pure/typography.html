Typography

A1 Pure maps the full A1 type scale to HTML elements via explicit a1-* class names. Apply the appropriate class to any element to get consistent heading, body, and inline text styling backed by design tokens.

Headings

All six semantic heading levels are styled with the A1 heading scale, progressing from display size at <h1> down to a compact label size at <h6>. Each heading element requires its corresponding a1-h* class.

<h1 class="a1-h1">Heading 1</h1>
<h2 class="a1-h2">Heading 2</h2>
<h3 class="a1-h3">Heading 3</h3>
<h4 class="a1-h4">Heading 4</h4>
<h5 class="a1-h5">Heading 5</h5>
<h6 class="a1-h6">Heading 6</h6>

Heading size modifiers

Override the default size for any heading level using a1-heading-size-* modifier classes. This decouples the semantic level from the visual scale — useful for hero text, section labels, or sub-headings.

<h2 class="a1-h2 a1-heading-size-xxl">Display XXL on an h2</h2>
<h1 class="a1-h1 a1-heading-size-md">Heading MD on an h1</h1>

Display type

Add a1-heading-type-display alongside a size modifier to switch to the display type treatment — a different font family, weight, and line height suited to hero and marketing headings.

<h1 class="a1-h1 a1-heading-type-display a1-heading-size-xl">Display XL</h1>
<h2 class="a1-h2 a1-heading-type-display a1-heading-size-lg">Display LG</h2>

Heading color modifiers

Change a heading's color using a1-heading-color-* modifier classes. These map directly to semantic color tokens.

<h3 class="a1-h3 a1-heading-color-default">Default color</h3>
<h3 class="a1-h3 a1-heading-color-muted">Muted color</h3>
<h3 class="a1-h3 a1-heading-color-accent">Accent color</h3>

Paragraphs

Apply class="a1-p" to any <p> element to get the standard body text treatment — medium size, body font family, and comfortable line height.

<p class="a1-p">Body text here.</p>

Muted text

Wrap content in <small class="a1-small"> to render it at a reduced size in the muted foreground color — suitable for captions, metadata, and supporting detail.

<p class="a1-p"><small class="a1-small">Supporting detail or caption text.</small></p>

Inline elements

Standard HTML inline elements are styled from A1 tokens. <strong> and <em> use element selectors. Links, code, keyboard shortcuts, highlights, and abbreviations require their a1-* class.

<strong>Bold</strong>
<em>Italic</em>
<a class="a1-link" href="#">Link</a>
<code class="a1-code">inline code</code>
<kbd class="a1-kbd">⌘K</kbd>
<mark class="a1-mark">Highlighted</mark>
<abbr title="HyperText Markup Language">HTML</abbr>

Blockquote — border

A <blockquote class="a1-blockquote"> by default receives a left-border treatment using the A1 border and spacing tokens.

Good design is as little design as possible. Less, but better — because it concentrates on the essential aspects, and the products are not burdened with non-essentials.

Dieter Rams — Ten Principles for Good Design 
<blockquote class="a1-blockquote">
  <p class="a1-p">Quote text here.</p>
  <cite>Author — Source</cite>
</blockquote>

Blockquote — feature

Wrapping a <blockquote class="a1-blockquote"> in a <figure class="a1-figure"> applies the feature variant — a centered, visually prominent treatment for pull quotes.

<figure class="a1-figure">
  <blockquote class="a1-blockquote">
    <p class="a1-p">Quote text here.</p>
    <cite>Author</cite>
  </blockquote>
</figure>

Blockquote — accent

Wrapping a <blockquote class="a1-blockquote"> in an <aside> applies an accent background — useful for callouts and highlighted asides within body copy.

Design is not just what it looks like and feels like. Design is how it works.

Steve Jobs 
<aside>
  <blockquote class="a1-blockquote">
    <p class="a1-p">Quote text here.</p>
    <cite>Author</cite>
  </blockquote>
</aside>

Code blocks

<code class="a1-code"> renders inline in the system monospace font with a subtle background. <pre class="a1-pre"><code class="a1-code"> adds a panel surface, border, and horizontal scrolling on narrow viewports.

<p class="a1-p">Inline <code class="a1-code">code</code> in a sentence.</p>

<pre class="a1-pre"><code class="a1-code">/* block code */
button { background: var(--token); }</code></pre>

Divider

Apply class="a1-hr" to an <hr> element to render a full-width horizontal rule using the subtle border token.

<p class="a1-p">Content above.</p>
<hr class="a1-hr">
<p class="a1-p">Content below.</p>

Lists

Both ordered and unordered lists receive proper indentation, spacing, and nested list support. Apply a1-ul or a1-ol to the list element. Nested lists use the same classes.

<ul class="a1-ul">
  <li>Item one</li>
  <li>Item two
    <ul class="a1-ul">
      <li>Nested item</li>
    </ul>
  </li>
</ul>

<ol class="a1-ol">
  <li>First step</li>
  <li>Second step</li>
</ol>
