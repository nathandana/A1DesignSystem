Get started

Icon

Icons use the Material Symbols Outlined variable font, loaded automatically by a1-pure.css. Apply class="a1-icon" to a <span> and put the icon name as the text content. Always add aria-hidden="true" — icons are decorative and the surrounding label provides meaning.

Basic icons

The icon name is the Material Symbols ligature string. Icons inherit font-size and color from their parent by default.

<span class="a1-icon" aria-hidden="true">add</span>
<span class="a1-icon" aria-hidden="true">close</span>
<span class="a1-icon" aria-hidden="true">check</span>

Sizes

Icons inherit font-size from their parent, so set font-size on the parent or use an inline style. Set --a1-icon-opsz to match the rendered size for optimal rendering quality (20, 24, or 40 are the system sizes).

<!-- 20px -->
<span class="a1-icon" aria-hidden="true" style="font-size:20px;--a1-icon-opsz:20;">notifications</span>

<!-- 24px -->
<span class="a1-icon" aria-hidden="true" style="font-size:24px;--a1-icon-opsz:24;">notifications</span>

<!-- 40px -->
<span class="a1-icon" aria-hidden="true" style="font-size:40px;--a1-icon-opsz:40;">notifications</span>

Filled variant

Add class="a1-icon-filled" alongside a1-icon to switch to the filled version of any icon. Alternatively, set --a1-icon-fill: 1 via inline style.

<!-- Outline (default) -->
<span class="a1-icon" aria-hidden="true">favorite</span>

<!-- Filled -->
<span class="a1-icon a1-icon-filled" aria-hidden="true">favorite</span>

Color

Icons inherit color from their parent. Set color on the parent element or use a utility style to apply status colors.

<!-- Inherits text color -->
<span class="a1-icon" aria-hidden="true">info</span>

<!-- Explicit status color via CSS custom property -->
<span class="a1-icon" aria-hidden="true" style="color:var(--semantic-color-status-error-background);">error</span>

Icon in button

Place an a1-icon before or after the button label. The button's flex layout aligns and centers the icon automatically. Icon size scales with the button size modifier.

<!-- Leading icon -->
<button class="a1-button">
  <span class="a1-icon" aria-hidden="true">add</span>
  Create
</button>

<!-- Trailing icon -->
<button class="a1-button">
  Download
  <span class="a1-icon" aria-hidden="true">download</span>
</button>

<!-- Small button with icon -->
<button class="a1-button a1-button-small">
  <span class="a1-icon" aria-hidden="true">add</span>
  Small
</button>

Icon button

Apply class="a1-icon-button" to a <button> for a square icon-only button. Always provide a meaningful aria-label since there is no visible text.

<button class="a1-icon-button" aria-label="Add">
  <span class="a1-icon" aria-hidden="true">add</span>
</button>

<button class="a1-icon-button" aria-label="Close">
  <span class="a1-icon" aria-hidden="true">close</span>
</button>

Icon button — disabled

Add the disabled attribute or aria-disabled="true" to render the icon button in a non-interactive state.

<button class="a1-icon-button" aria-label="Add" disabled>
  <span class="a1-icon" aria-hidden="true">add</span>
</button>

Icon in link

An a1-icon inside an a1-link renders at 1em — matching the surrounding text size. The link uses inline-flex with align-items: baseline for proper text alignment.

<a class="a1-link" href="#">
  <span class="a1-icon" aria-hidden="true">arrow_forward</span>
  Read the documentation
</a>

<a class="a1-link" href="#" target="_blank" rel="noopener noreferrer">
  Opens in a new tab
  <span class="a1-icon" aria-hidden="true">open_in_new</span>
</a>

Accessibility

  • Always add aria-hidden="true" to icons — they are decorative and the surrounding context provides meaning.
  • For icon buttons, always include a descriptive aria-label on the button element itself.
  • Never rely on icon color alone to convey information — always pair with text or other visual cues.
  • Use a1-icon-filled to indicate state changes (e.g. bookmarked vs. not), not just for decoration.
