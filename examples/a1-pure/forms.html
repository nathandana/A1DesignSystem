Get started

Forms

Apply a1-label to the wrapping <label> and the matching a1-input, a1-select, or a1-textarea to the control. The label uses display: grid so label text, input, and messages stack automatically. Size, required, and status modifier classes all go on the label.

Sizes

Add a1-label-compact or a1-label-comfortable to scale the label font, input height, padding, and border-radius together. The default (no size class) is the medium size.

<!-- Compact -->
<label class="a1-label a1-label-compact">
  Compact
  <input class="a1-input" type="text">
</label>

<!-- Default (no size class) -->
<label class="a1-label">
  Default
  <input class="a1-input" type="text">
</label>

<!-- Comfortable -->
<label class="a1-label a1-label-comfortable">
  Comfortable
  <input class="a1-input" type="text">
</label>

Text input

Wrap an <input class="a1-input"> inside a <label class="a1-label">. The label text and input stack automatically via the grid layout.

<label class="a1-label">
  Full name
  <input class="a1-input" type="text">
</label>

Email input

Use type="email" for email addresses. Mobile browsers show an optimized keyboard.

<label class="a1-label">
  Email address
  <input class="a1-input" type="email">
</label>

Password input

Use type="password" to mask the entered value.

<label class="a1-label">
  Password
  <input class="a1-input" type="password">
</label>

Number input

Use type="number" for numeric values. Browsers render increment/decrement controls.

<label class="a1-label">
  Quantity
  <input class="a1-input" type="number" min="0">
</label>

Textarea

A <textarea class="a1-textarea"> inside an a1-label uses the same grid layout. Height scales with the size modifier if one is applied.

<label class="a1-label">
  Message
  <textarea class="a1-textarea"></textarea>
</label>

Select

A <select class="a1-select"> is styled with the same border, radius, and padding as text inputs. Size modifiers apply the same way.

<label class="a1-label">
  Category
  <select class="a1-select">
    <option>Design systems</option>
    <option>Accessibility</option>
    <option>Frontend engineering</option>
    <option>Product strategy</option>
  </select>
</label>

Hint text

Place a <small class="a1-message-hint"> after the input inside the label. The grid layout stacks it beneath the input automatically.

<label class="a1-label">
  Username
  <input class="a1-input" type="text">
  <small class="a1-message-hint">Only letters, numbers, and underscores.</small>
</label>

Required field

Add the required attribute to the input. CSS automatically applies a blue left accent border. Use <span class="a1-required">*</span> in the label text to show the required asterisk.

<label class="a1-label">
  Email address <span class="a1-required">*</span>
  <input class="a1-input" type="email" required>
  <small class="a1-message-hint">We'll never share your email.</small>
</label>

Error state

Add a1-label-error to the label. The input gets a red left accent border and a thicker red border. Use <small class="a1-message-error"> for the error message.

<label class="a1-label a1-label-error">
  Email address
  <input class="a1-input" type="email" value="not-an-email">
  <small class="a1-message-error">Please enter a valid email address.</small>
</label>

Success state

Add a1-label-success to the label. The input gets a green left accent border. Use <small class="a1-message-success"> for the confirmation message.

<label class="a1-label a1-label-success">
  Username
  <input class="a1-input" type="text" value="nathandana">
  <small class="a1-message-success">Username is available.</small>
</label>

Disabled field

The disabled attribute reduces opacity and sets cursor: not-allowed. Works with any size modifier or status state.

<label class="a1-label">
  Account ID
  <input class="a1-input" type="text" value="ACC-00412" disabled>
</label>

Interactive states

All interactive states are driven by CSS pseudo-classes — no JavaScript required.

  • Default — border from --semantic-color-border-default
  • Hover — :hover — shifted border color and background tint
  • Focus — :focus-visible — focus ring using --component-field-focus-ring-color
  • Disabled — :disabled — reduced opacity, cursor: not-allowed
  • Required — blue left accent border, auto-applied via :has(input:required)
  • Error — a1-label-error — red border with red left accent
  • Success — a1-label-success — green left accent

Full form example

Apply class="a1-form" to the <form> element to get a display: grid layout with the system gap (--semantic-spacing-gap-md) between each field.

<form class="a1-form">
  <label class="a1-label">
    Full name <span class="a1-required">*</span>
    <input class="a1-input" type="text" required>
  </label>
  <label class="a1-label a1-label-error">
    Email address <span class="a1-required">*</span>
    <input class="a1-input" type="email" required>
    <small class="a1-message-error">Please enter a valid email address.</small>
  </label>
  <label class="a1-label a1-label-success">
    Username
    <input class="a1-input" type="text">
    <small class="a1-message-success">Username is available.</small>
  </label>
  <button class="a1-button" type="submit">Send message</button>
</form>
