Forms

Text inputs, selects, and textareas are styled at the element level. A <label> uses display: grid so the label text, input, and any help text stack vertically — no wrapper div required.

Text input

Wrap an <input> inside a <label>. The label text and input stack automatically.

<label>
  Full name
  <input type="text" placeholder="Ada Lovelace">
</label>

Email input

Use type="email" for email addresses. Mobile browsers will show an optimized keyboard.

<label>
  Email address
  <input type="email" placeholder="ada@example.com">
</label>

Password input

Use type="password" to mask the entered value.

<label>
  Password
  <input type="password" placeholder="Enter your password">
</label>

Number input

Use type="number" for numeric values. Browsers render increment/decrement controls.

<label>
  Quantity
  <input type="number" placeholder="0" min="0">
</label>

Textarea

A <textarea> inside a <label> stacks with the same grid layout as text inputs.

<label>
  Message
  <textarea placeholder="Write here…"></textarea>
</label>

Select

A native <select> is styled with the same border, radius, and padding as text inputs.

<label>
  Category
  <select>
    <option>Design systems</option>
    <option>Accessibility</option>
    <option>Frontend engineering</option>
    <option>Product strategy</option>
  </select>
</label>

Disabled field

The disabled attribute reduces opacity and sets cursor: not-allowed. The field cannot receive focus or input.

<label>
  Account ID
  <input type="text" value="ACC-00412" disabled>
</label>

Help text

Place a <small> element after the input, inside the <label>. The grid layout stacks it beneath the input automatically.

<label>
  Username
  <input type="text" placeholder="yourname">
  <small>Only letters, numbers, and underscores.</small>
</label>

Full form example

A complete form combining multiple field types. All styling is applied by element selectors — no class attributes required.

<form>
  <label>
    Full name
    <input type="text" placeholder="Ada Lovelace">
  </label>
  <label>
    Email address
    <input type="email" placeholder="ada@example.com">
  </label>
  <label>
    Category
    <select>
      <option>Design systems</option>
      <option>Accessibility</option>
    </select>
  </label>
  <label>
    Message
    <textarea placeholder="Tell us what you're building…"></textarea>
  </label>
  <button type="submit">Send message</button>
</form>
