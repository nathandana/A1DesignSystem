Circular Progress

Use Circular Progress to communicate loading state or a completion percentage with a circular ring. Static values show how much of a task is done; indeterminate mode shows an activity spinner. Custom content — percentage labels, icons, or status text — sits inside the ring for all sizes except xs, which places content inline after the ring.

Default (md)

Set --a1-cp-pct on the __ring element as a decimal from 0 to 1. Always provide role="progressbar", aria-valuenow, aria-valuemin, aria-valuemax, and aria-label.

21% complete
65% uploaded
check_circle 
<div class="a1-circular-progress"
     role="progressbar" aria-valuenow="21" aria-valuemin="0" aria-valuemax="100" aria-label="21% complete">
  <div class="a1-circular-progress__ring" style="--a1-cp-pct:0.21"></div>
  <div class="a1-circular-progress__inner">
    <span class="a1-h3" style="line-height:1">21%</span>
    <span class="a1-p" style="font-size:var(--semantic-font-size-body-xs);color:var(--semantic-color-text-muted);margin-top:var(--base-spacing-4)">complete</span>
  </div>
</div>

Indeterminate (loading)

Add a1-circular-progress-indeterminate for a continuously spinning arc. Remove aria-valuenow so assistive technology announces an indeterminate state. Omit --a1-cp-pct on the ring — the arc length is a fixed 25% set by the animation.

Loading…
73% verifying…
Saving… 
<div class="a1-circular-progress a1-circular-progress-indeterminate"
     role="progressbar" aria-valuemin="0" aria-valuemax="100" aria-label="Loading">
  <div class="a1-circular-progress__ring" style="--a1-cp-pct:0.25"></div>
  <div class="a1-circular-progress__inner">
    <span class="a1-p" style="font-size:var(--semantic-font-size-body-xs);color:var(--semantic-color-text-muted)">Loading…</span>
  </div>
</div>

Token overrides

Override --a1-cp-fill and --a1-cp-track to change ring colors without altering the token source.

85%
12% 
<div class="a1-circular-progress"
     style="--a1-cp-fill:var(--semantic-color-status-success-background);
            --a1-cp-track:var(--semantic-color-status-success-surface)"
     role="progressbar" aria-valuenow="85" aria-valuemin="0" aria-valuemax="100" aria-label="85% healthy">
  <div class="a1-circular-progress__ring" style="--a1-cp-pct:0.85"></div>
  <div class="a1-circular-progress__inner">
    <span class="a1-h4" style="color:var(--semantic-color-status-success-background)">85%</span>
  </div>
</div>
