A1 Design System

Beautiful HTML, out of the box.

A1 Pure is a classless stylesheet that applies the A1 design token system directly to standard HTML elements. Write clean, semantic markup and let the stylesheet handle the rest — no class names, no frameworks, no build step.

Why PURE?

Enterprises are full of ancient interfaces — internal tools, legacy portals, random web pages built across decades by teams who've long moved on. Updating them to the latest React library isn't realistic: the capacity isn't there, the risk is too high, and the ROI is hard to justify.

A1 Pure offers a lower bar of entry. Drop in one stylesheet, add a handful of class names, and a page that looked like 2003 starts looking like a coherent product. No build step, no npm, no framework lock-in. It's a step toward consistency that any team can deliver.

  • Works in any HTML page — no framework, no build pipeline
  • Additive by design — add classes where you want A1 styling, leave the rest alone
  • Shares the same design tokens as the React component library — consistent by construction
  • Swap the theme file to change the entire look without touching markup

Get started

Add a single <link> tag to the <head> of your document.

<link rel="stylesheet" href="a1-pure.css">
  1. Write semantic HTML — <h1>, <p>, <ul>, <form>, and so on.
  2. Link a1-pure.css. The stylesheet handles all visual styling automatically.
  3. To change the theme, swap the imported token file inside a1-pure.css.
  4. Override individual properties using CSS custom properties when you need to diverge from the defaults.
