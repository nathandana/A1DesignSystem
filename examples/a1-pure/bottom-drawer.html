Bottom Drawer

Fixed bottom navigation bar for mobile viewports. Up to 5 items, each with an icon stacked above a short label. Uses the same --a1-nav-stacked-* CSS custom properties as the TopHeader icon-above nav so both remain visually consistent.

Default — 5 items

All five slots filled. Each item renders as an <a> with icon above label. The active item uses the accent color.

Responsive pattern — TopHeader + BottomDrawer

At xs (≤480px): set the TopHeader to navIconPosition="hidden" and show the BottomDrawer. At sm+ (≥481px): hide the BottomDrawer and show the TopHeader nav with icon-above layout. Both components share the same nav items array.

/* Show BottomDrawer on xs only */
@media (min-width: 481px) {
  .bottom-drawer { display: none; }
}

/* Show TopHeader nav (icon-above) on sm+ only */
/* TopHeader with navIconPosition={{ xs: "hidden", sm: "above", lg: "start" }} */
