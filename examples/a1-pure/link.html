Get started

Link

Apply class="a1-link" to any <a> element for inline link styling — the A1 link color, underline, and all interactive states. For a button-styled link, use class="a1-button" instead.

Default

A bare <a class="a1-link"> renders with the A1 link color and an underline. Color and offset come from component link tokens.

<a class="a1-link" href="#">This is a link</a>

Inline in text

Links sit naturally inside paragraphs and list items. The underline color, offset, and interactive states are consistent regardless of surrounding text size.

<p class="a1-p">
  Use <a class="a1-link" href="#">design tokens</a> to keep styles consistent.
</p>

In a list

Links inside list items work the same as inline links. No extra classes are needed on the <li>.

<ul class="a1-ul">
  <li><a class="a1-link" href="#">Typography</a> — description</li>
  <li><a class="a1-link" href="#">Button</a> — description</li>
</ul>

External link

For links that open in a new tab, add target="_blank" and rel="noopener noreferrer". No additional class is needed — the same a1-link style applies.

<a class="a1-link" href="https://example.com" target="_blank" rel="noopener noreferrer">
  Opens in a new tab
</a>

Interactive states

All states are handled by CSS — no JavaScript required.

  • Default — link color from --component-link-color with underline
  • Visited — :visited — same color as default to maintain brand consistency
  • Hover — :hover — shifted color from --component-link-color-hover
  • Active — :active — pressed color from --component-link-color-pressed
  • Focus-visible — :focus-visible — visible focus ring using the field focus ring token, shown only for keyboard navigation

Link vs button

Use a1-link for navigating to a URL. Use a1-button on an <a> when the visual treatment should be a button — for example, a prominent call-to-action that links to another page.

<!-- Inline navigation -->
<a class="a1-link" href="#">Read the docs</a>

<!-- Prominent call to action -->
<a class="a1-button" href="#">Get started</a>
