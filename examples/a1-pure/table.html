Table

Apply class="a1-table" to a <table> element for a full-width, border-collapsed table with styled header cells, row separators, and consistent cell padding from design tokens.

Basic table

A standard table with a header row and body rows. Use <thead>, <tbody>, <th>, and <td> elements — no additional classes needed beyond a1-table on the <table>.

<table class="a1-table">
  <thead>
    <tr>
      <th>Name</th>
      <th>Role</th>
      <th>Status</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Ada Lovelace</td>
      <td>Engineer</td>
      <td>Active</td>
    </tr>
  </tbody>
</table>

With mixed content

Table cells can contain any inline A1 elements — code, links, badges — using their respective a1-* classes.

<table class="a1-table">
  <thead>
    <tr>
      <th>Token</th>
      <th>Value</th>
      <th>Usage</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td><code class="a1-code">--token-name</code></td>
      <td><code class="a1-code">#value</code></td>
      <td>Description</td>
    </tr>
  </tbody>
</table>

Row headers

Use <th scope="row"> in the body to mark row headers — useful for comparison tables and property lists.

<table class="a1-table">
  <thead>
    <tr>
      <th>Property</th>
      <th>Value</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">Border radius</th>
      <td><code class="a1-code">--component-button-border-radius</code></td>
    </tr>
  </tbody>
</table>

With caption

A <caption> provides an accessible title for the table, announced by screen readers and rendered above the table content.

<table class="a1-table">
  <caption>Q2 component releases</caption>
  <thead>
    <tr>
      <th>Component</th>
      <th>Version</th>
      <th>Status</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Button</td>
      <td>2.4.0</td>
      <td>Stable</td>
    </tr>
  </tbody>
</table>

With footer

A <tfoot> row receives the same cell styling as body rows. Use it for totals, summaries, or persistent labels.

<table class="a1-table">
  <thead>
    <tr>
      <th>Item</th>
      <th>Qty</th>
      <th>Price</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Row data</td>
      <td>1</td>
      <td>$0</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <td><strong>Total</strong></td>
      <td><strong>1</strong></td>
      <td><strong>$0</strong></td>
    </tr>
  </tfoot>
</table>
