Segmented Control

A raised track of mutually exclusive segments. Apply class="a1-segmented" to the track and class="a1-segment" to each option. Track heights sit on the 28/40/56 control-height standard — the outer control lands exactly on the standard and the segments derive their height from it.

Sizes

The default track is 40px tall. Add a1-segmented-small (28px) or a1-segmented-large (56px).

<div class="a1-segmented a1-segmented-small" role="radiogroup" aria-label="View density (small)">
  <button type="button" class="a1-segment" role="radio" aria-checked="true">Day</button>
  <button type="button" class="a1-segment" role="radio" aria-checked="false">Week</button>
  <button type="button" class="a1-segment" role="radio" aria-checked="false">Month</button>
</div>

<div class="a1-segmented" role="radiogroup" aria-label="View density (medium)">

Full width

Add a1-segmented-full-width to fill the container; segments share the width equally.

<div class="a1-segmented a1-segmented-full-width" role="radiogroup" aria-label="Billing period">
  <button type="button" class="a1-segment" role="radio" aria-checked="false">Monthly</button>
  <button type="button" class="a1-segment" role="radio" aria-checked="true">Yearly</button>
</div>

Selection state

The selected segment is styled from aria-checked="true" (radiogroup pattern) or aria-selected="true" (tablist pattern). Use the a1-segment-selected modifier only when neither ARIA pattern applies. Toggle the state with your own script — A1 Pure ships no behavior.

  • Selected — page surface on the raised track with the --semantic-shadow-xs lift
  • Hover — unselected segments shift to the panel surface with default text
  • Focus-visible — inset focus ring from the shared button focus token
