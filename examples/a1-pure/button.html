Get started

Button

Apply class="a1-button" to a <button> or <a> element. Combine with type, size, and shape modifier classes. All interactive states are handled by CSS — no JavaScript required.

Types

Three visual types cover the full hierarchy of actions. Apply a1-button-secondary or a1-button-tertiary alongside a1-button. The default (no type class) is primary.

<!-- Primary (default) -->
<button class="a1-button">Primary</button>

<!-- Secondary -->
<button class="a1-button a1-button-secondary">Secondary</button>

<!-- Tertiary -->
<button class="a1-button a1-button-tertiary">Tertiary</button>

Sizes

Three sizes scale the height, font size, and padding. Add a1-button-small or a1-button-large to any type. The default (no size class) is the medium size.

<button class="a1-button a1-button-small">Small</button>
<button class="a1-button">Medium (default)</button>
<button class="a1-button a1-button-large">Large</button>

Shape

Add a1-button-pill to any type and size to apply a fully rounded border-radius. Works as a modifier on top of any combination.

<button class="a1-button a1-button-pill">Pill primary</button>
<button class="a1-button a1-button-secondary a1-button-pill">Pill secondary</button>
<button class="a1-button a1-button-tertiary a1-button-pill">Pill tertiary</button>

Combining modifiers

Type, size, and shape modifiers compose freely. Any combination is valid.

<button class="a1-button a1-button-secondary a1-button-small">Secondary small</button>
<button class="a1-button a1-button-secondary a1-button-large">Secondary large</button>
<button class="a1-button a1-button-tertiary a1-button-small a1-button-pill">Tertiary small pill</button>
<button class="a1-button a1-button-large a1-button-pill">Primary large pill</button>

Disabled

Add the disabled attribute to render any button in its disabled state — reduced opacity, cursor: not-allowed, no interaction. Works with all types and sizes.

<button class="a1-button" disabled>Primary disabled</button>
<button class="a1-button a1-button-secondary" disabled>Secondary disabled</button>
<button class="a1-button a1-button-tertiary" disabled>Tertiary disabled</button>

Aria disabled

Use aria-disabled="true" when the button must remain focusable (e.g. to show a tooltip explaining why it is disabled). The visual state is identical to the disabled attribute but the element stays in the tab order.

<button class="a1-button" aria-disabled="true">Aria disabled</button>

As a link

Apply class="a1-button" to an <a> element to render it with button styling. All type, size, and shape modifiers work identically. Without the button class, use class="a1-link" for standard inline link styling.

<a class="a1-button" href="#">Button link — primary</a>
<a class="a1-button a1-button-secondary" href="#">Button link — secondary</a>

<!-- Standard inline link -->
<a class="a1-link" href="#">Inline link</a>

In a form

A <button class="a1-button" type="submit"> inside a <form> submits the form. All button modifiers apply normally.

<form>
  <label class="a1-label">
    Email address
    <input class="a1-input" type="email" placeholder="you@example.com">
  </label>
  <button class="a1-button" type="submit">Subscribe</button>
</form>

Interactive states

All states are driven entirely by CSS pseudo-classes — no JavaScript required.

  • Default — resting appearance; background, border, and foreground from the active type's tokens
  • Hover — :hover — slightly shifted background or border color
  • Active / pressed — :active — darkest state while the button is held
  • Focus-visible — :focus-visible — visible focus ring using --component-button-focus-ring, only shown for keyboard navigation
  • Disabled — :disabled or aria-disabled="true" — reduced opacity, cursor: not-allowed; hover and active states suppressed
