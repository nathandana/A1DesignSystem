Get started

Button

The <button> element maps directly to the A1 primary button style. No class name is required — a bare button element is a fully styled primary action button.

Default

A plain <button> element renders as the primary A1 button.

<button>Click me</button>

Disabled

Add the disabled attribute to render the button in a reduced-opacity, non-interactive state.

<button disabled>Disabled</button>

As a link

The <a> element receives link styling — underlined text in the link color token — not button styling. In A1 Pure, there is no classless way to make a link look like a button. For a button-styled link, use the BEM class package (.a1-button on an anchor element).

<a href="#">Link styled as an anchor</a>

In a form

A <button type="submit"> inside a <form> submits the form. It receives the same primary button styling.

<form>
  <label>
    Email address
    <input type="email" placeholder="you@example.com">
  </label>
  <button type="submit">Subscribe</button>
</form>

Interactive states

Hover, active, and focus-visible states are handled entirely by CSS. No JavaScript is required. Interact with any of the buttons above to see the states in action.

  • Default — primary background color from --component-button-primary-background
  • Hover — slightly darker background
  • Active — darkest background, slight scale reduction
  • Focus-visible — visible focus ring using the A1 focus token, for keyboard navigation
  • Disabled — reduced opacity, cursor: not-allowed, no interaction
