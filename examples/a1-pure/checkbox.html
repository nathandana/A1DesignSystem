Checkbox

Checkboxes and radio buttons are styled at the element level. Wrap each <input type="checkbox"> or <input type="radio"> inside a <label> — the label uses flexbox to align the control and text side by side. Group related controls in a <fieldset> with a <legend>.

Single checkbox

Each state — unchecked, checked, disabled unchecked, and disabled checked — is demonstrated below. The control and label text are vertically centered by label:has(> input[type="checkbox"]).

<label><input type="checkbox"> Unchecked</label>
<label><input type="checkbox" checked> Checked</label>
<label><input type="checkbox" disabled> Disabled unchecked</label>
<label><input type="checkbox" checked disabled> Disabled checked</label>

Checkbox group

Use <fieldset> and <legend> to group related checkboxes. The fieldset provides the border and the legend labels the group.

<fieldset>
  <legend>Notification preferences</legend>
  <label><input type="checkbox" checked> Email notifications</label>
  <label><input type="checkbox"> Push notifications</label>
  <label><input type="checkbox"> SMS alerts</label>
  <label><input type="checkbox" checked> Weekly digest</label>
</fieldset>

Radio group

Radio inputs share the same label and fieldset pattern. Only one option can be selected at a time within a group (by matching name attribute).

<fieldset>
  <legend>Delivery method</legend>
  <label><input type="radio" name="delivery" checked> Standard (3–5 days)</label>
  <label><input type="radio" name="delivery"> Express (1–2 days)</label>
  <label><input type="radio" name="delivery"> Overnight</label>
</fieldset>

Indeterminate state

The indeterminate state — a dash instead of a check — cannot be set with an HTML attribute alone. It requires JavaScript to set the indeterminate property on the element directly.

const checkbox = document.querySelector('input[type="checkbox"]');
checkbox.indeterminate = true;

This is commonly used for "select all" controls where only some children are checked. The CSS renders the appropriate visual state once the property is set.

Accessibility notes

  • Always associate a label with every checkbox or radio input — wrapping the input inside the <label> element is the simplest way to do this.
  • Always group related checkboxes and radios with <fieldset> and <legend> so screen readers announce the group name alongside each option.
  • If you add supplemental help text outside the label, use aria-describedby to connect it to the input.
