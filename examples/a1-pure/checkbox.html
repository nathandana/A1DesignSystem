Get started

Checkbox

Checkboxes and radios use a1-checkbox and a1-radio on the input, and a1-label on the wrapping element. Groups use <fieldset class="a1-fieldset"> — no border, legend sits directly above the items. Wrap items in .a1-fieldset-items to enable hint text, error, and success states.

Single checkbox

All four states — unchecked, checked, disabled unchecked, disabled checked. The a1-label switches to flex layout automatically when it contains a checkbox or radio.

<label class="a1-label"><input class="a1-checkbox" type="checkbox"> Unchecked</label>
<label class="a1-label"><input class="a1-checkbox" type="checkbox" checked> Checked</label>
<label class="a1-label"><input class="a1-checkbox" type="checkbox" disabled> Disabled unchecked</label>
<label class="a1-label"><input class="a1-checkbox" type="checkbox" checked disabled> Disabled checked</label>

Checkbox group

Use <fieldset class="a1-fieldset"> with a <legend> and <div class="a1-fieldset-items">. The fieldset is borderless — the legend sits directly above the items.

<fieldset class="a1-fieldset">
  <legend>Notification preferences</legend>
  <div class="a1-fieldset-items">
    <label class="a1-label"><input class="a1-checkbox" type="checkbox" checked> Email notifications</label>
    <label class="a1-label"><input class="a1-checkbox" type="checkbox"> Push notifications</label>
    <label class="a1-label"><input class="a1-checkbox" type="checkbox"> SMS alerts</label>
  </div>
</fieldset>

With group hint text

Place a <p class="a1-fieldset-hint"> between the legend and the items wrapper. The items wrapper removes its top margin automatically when hint text is present.

<fieldset class="a1-fieldset">
  <legend>Notification preferences</legend>
  <p class="a1-fieldset-hint">Select all that apply.</p>
  <div class="a1-fieldset-items">
    <label class="a1-label"><input class="a1-checkbox" type="checkbox" checked> Email notifications</label>
    <label class="a1-label"><input class="a1-checkbox" type="checkbox"> Push notifications</label>
  </div>
</fieldset>

With item hint text

Wrap label text and hint in <span class="a1-label-content">. The hint uses <span class="a1-label-hint">. The checkbox aligns to the label cap-height automatically.

<label class="a1-label">
  <input class="a1-checkbox" type="checkbox">
  <span class="a1-label-content">
    Label text
    <span class="a1-label-hint">Hint text below the label</span>
  </span>
</label>

Error state

Add a1-fieldset-error to the fieldset. The items wrapper gets a red left accent border. The error message uses a1-fieldset-message a1-fieldset-message-error.

<fieldset class="a1-fieldset a1-fieldset-error">
  <legend>Notification preferences</legend>
  <div class="a1-fieldset-items">
    <label class="a1-label"><input class="a1-checkbox" type="checkbox"> Email notifications</label>
    <label class="a1-label"><input class="a1-checkbox" type="checkbox"> Push notifications</label>
  </div>
  <p class="a1-fieldset-message a1-fieldset-message-error">Please select at least one notification type.</p>
</fieldset>

Success state

Add a1-fieldset-success to the fieldset. The items wrapper gets a green left accent border and the success message is styled accordingly.

<fieldset class="a1-fieldset a1-fieldset-success">
  <legend>Notification preferences</legend>
  <div class="a1-fieldset-items">
    <label class="a1-label"><input class="a1-checkbox" type="checkbox" checked> Email notifications</label>
  </div>
  <p class="a1-fieldset-message a1-fieldset-message-success">Preferences saved successfully.</p>
</fieldset>

Radio group

Radio inputs use class="a1-radio" with the identical fieldset pattern. Only one option can be selected at a time within a group (matched by name attribute).

<fieldset class="a1-fieldset">
  <legend>Delivery method</legend>
  <div class="a1-fieldset-items">
    <label class="a1-label"><input class="a1-radio" type="radio" name="delivery" checked> Standard (3–5 days)</label>
    <label class="a1-label"><input class="a1-radio" type="radio" name="delivery"> Express (1–2 days)</label>
    <label class="a1-label"><input class="a1-radio" type="radio" name="delivery"> Overnight</label>
  </div>
</fieldset>

Radio group — error state

Same pattern as the checkbox error state — a1-fieldset-error on the fieldset and an error message after the items wrapper.

<fieldset class="a1-fieldset a1-fieldset-error">
  <legend>Delivery method</legend>
  <div class="a1-fieldset-items">
    <label class="a1-label"><input class="a1-radio" type="radio" name="delivery"> Standard</label>
    <label class="a1-label"><input class="a1-radio" type="radio" name="delivery"> Express</label>
  </div>
  <p class="a1-fieldset-message a1-fieldset-message-error">Please select a delivery method.</p>
</fieldset>

Indeterminate state

The indeterminate state requires JavaScript — it cannot be set via an HTML attribute alone.

const checkbox = document.querySelector('.a1-checkbox');
checkbox.indeterminate = true;

Commonly used for "select all" controls where only some children are checked. The browser renders the intermediate visual state once the property is set.

Accessibility notes

  • Always wrap each input inside its <label> — the simplest way to associate them without needing for/id.
  • Always use <fieldset> and <legend> for groups so screen readers announce the group name alongside each option.
  • If supplemental help text lives outside the label, link it with aria-describedby.
