## Intent
Pure is an example application that uses only HTML and CSS to showcase the Pure version of the A1 design system.

## Rules
Only use the pure A1 package for markup. CSS can be created only when absolutely necessary. Markhup should be as simple as possible. 

## Additional Context
A1 Pure needs to be properly scoped to ensure it doesn't have conflict with existing styles. "a1-*" prefixed classes everywhere.
